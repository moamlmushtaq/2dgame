# ☁️ سفينة الغيوم (Cloud Ship)

لعبة ثنائية الأبعاد **تعاونية** من لاعب واحد إلى **6 لاعبين** على شاشة واحدة، مصنوعة بمحرك **Godot 4**.

أنتم طاقم سفينة طائرة صغيرة تبحث عن قطع خريطة السماء الضائعة. في كل رحلة يجب أن تحافظوا على السفينة في الجو حتى تصلوا إلى جزيرة عائمة، ثم تحلّوا ألغازها معًا لتفتحوا صندوق الكنز.

---

## 🎮 طريقة اللعب

### ⛵ المرحلة الأولى: الرحلة على السفينة
كل واحد في الطاقم يختار مهمته، وتتغير الأدوار باستمرار:

| المهمة | ماذا تفعل |
|---|---|
| 🔥 **المحرك** | خذ فحمًا من الصندوق وضعه في المحرك. إذا نفد الوقود تصبح السفينة بطيئة جدًا |
| ⚓ **الدفة** | ارفع السفينة أو اخفضها لتتفادى الصخور العائمة. الأسهم الحمراء على يمين الشاشة تحذّرك |
| 💣 **المدافع** | مدفع في المقدمة ومدفع فوق الصاري. أسقط طيور العاصفة واكسر الصخور (3 ضربات) |
| 🔨 **الإصلاح** | الطيور والصخور تُحدث ثقوبًا في السطح. قف بجانب الثقب واضغط التفاعل باستمرار. كلما زاد عدد المصلحين كان الإصلاح أسرع |

### 🏝️ المرحلة الثانية: الجزيرة العائمة
- **الجدار العالي**: لا يستطيع أحد القفز فوقه وحده. اقفز فوق رأس صديقك، ثم اسحب الرافعة لتظهر درجة يصعد عليها الباقون.
- **البوابة والألواح**: البوابة تبقى مفتوحة ما دام أحد واقفًا على لوح الضغط. من سيبقى في الخلف ليفتحها للآخرين؟
- **مصعد البالونات**: لا يرتفع إلا بعدد كافٍ من الركاب، وفي الأعلى رافعة تجعله يعمل وحده.
- **صندوق الكنز**: لا يُفتح إلا إذا اجتمع الطاقم كله حوله.
- **البلورات** 💎: مكافآت إضافية، وبعضها عالٍ جدًا ولا يُصل إليه إلا ببرج من الأصدقاء!

الصعوبة تزداد مع عدد اللاعبين ومع كل رحلة جديدة.

## 🕹️ التحكم

| | الحركة | القفز | التفاعل |
|---|---|---|---|
| **كيبورد 1** | `W A S D` | `Space` | `E` |
| **كيبورد 2** | الأسهم | `.` أو `Enter` | `/` |
| **يد التحكم** | العصا اليسرى أو الأسهم | `A` | `X` أو `B` |

- في القائمة: **اضغط زر القفز للانضمام**، ثم **زر التفاعل للإبحار**.
- لاعبان على الكيبورد، ويمكن أن يكون الجميع (حتى 6) بأيدي التحكم.
- **النزول من المنصات**: الأسفل + القفز.
- **المدفع**: الأعلى/الأسفل للتصويب (مدفع الصاري يدور بالأيمن/الأيسر أيضًا)، والقفز لإطلاق النار.
- **Esc**: العودة إلى القائمة.

## 🚀 تشغيل اللعبة

1. نزّل **Godot 4.7** (النسخة العادية وليس .NET) من [godotengine.org](https://godotengine.org/download).
2. افتح Godot واضغط **Import** واختر ملف `project.godot` من مجلد اللعبة.
3. اضغط **F5** أو زر ▶️ للتشغيل.

> لتجربة مرحلة واحدة مباشرة: افتح `scenes/voyage.tscn` أو `scenes/island.tscn` واضغط **F6**، وسيضيف المحرك لاعبَين على الكيبورد تلقائيًا.

## 🔗 ربط GitHub مع Godot على جهازك

الفكرة ببساطة: المستودع على GitHub هو **النسخة الأصلية**، ونسخة على جهازك تفتحها بـ Godot. تعدّل على جهازك ثم ترفع التعديلات (Push)، وتسحب التعديلات الجديدة (Pull) من GitHub.

### الطريقة الأسهل: GitHub Desktop (أنصح بها)
1. نزّل [GitHub Desktop](https://desktop.github.com/) وسجّل الدخول بحسابك.
2. من القائمة: **File ← Clone repository**، واختر `moamlmushtaq/2dgame`، ثم حدّد مجلدًا على جهازك.
3. من الأعلى اختر الفرع (Branch) الذي فيه اللعبة، مثل `claude/bold-cori-f0jmgp`، أو `main` بعد الدمج.
4. افتح Godot ← **Import** ← اختر `project.godot` من المجلد نفسه.
5. بعد أي تعديل في Godot، ارجع إلى GitHub Desktop:
   - اكتب وصفًا قصيرًا في خانة **Summary** ثم اضغط **Commit**.
   - اضغط **Push origin** لرفع التعديل إلى GitHub.
6. لجلب تعديلات جديدة من GitHub (مثل التي أضيفها لك): اضغط **Fetch origin** ثم **Pull**.

### الطريقة الثانية: من سطر الأوامر
```bash
# مرة واحدة فقط
git clone https://github.com/moamlmushtaq/2dgame.git
cd 2dgame
git checkout claude/bold-cori-f0jmgp

# بعد كل تعديل
git add .
git commit -m "وصف التعديل"
git push

# لجلب التعديلات الجديدة
git pull
```

### الطريقة الثالثة: من داخل Godot نفسه (إضافة Git)
1. في Godot افتح تبويب **AssetLib** وابحث عن **Godot Git Plugin**، ثم ثبّتها.
2. أعد تشغيل المحرر، ثم من القائمة: **Project ← Version Control ← Version Control Settings**.
3. فعّل Git، وأدخل اسم المستخدم وبريدك. لكلمة المرور استخدم **Personal Access Token** من GitHub:
   GitHub ← Settings ← Developer settings ← Personal access tokens، مع صلاحية `repo`.
4. ستظهر لوحة **Commit** في المحرر، ومنها تقدر تعمل Commit و Push و Pull.

> 💡 مجلد `.godot/` محلي ولا يُرفع إلى GitHub (موجود في `.gitignore`)، ويُنشئه Godot تلقائيًا عند فتح المشروع.

## 📁 هيكل المشروع

```
project.godot            إعدادات المشروع
scenes/                  المشاهد: القائمة، الرحلة، الجزيرة
scripts/core/            اللاعب، التحكم، الحالة العامة، الرسم، السماء
scripts/voyage/          السفينة والمحطات والمخاطر وواجهة الرحلة
scripts/island/          الجزيرة والألغاز وواجهة الجزيرة
scripts/menu/            شاشة البداية وانضمام اللاعبين
assets/fonts/            خط Cairo العربي (رخصة OFL)
```

كل الرسومات مرسومة بالكود، فلا توجد صور خارجية. هذا يسهّل التعديل: غيّر الألوان أو الأشكال في الكود وسترى النتيجة فورًا.
