# ☁️ سفينة الغيوم (Cloud Ship)

لعبة ثنائية الأبعاد **تعاونية** من لاعب واحد إلى **6 لاعبين** على شاشة واحدة، مصنوعة بمحرك **Godot 4**.

أنتم طاقم سفينة طائرة صغيرة. مزّقت عاصفةٌ **خريطة السماء** إلى 4 قطع وبعثرتها على الجزر العائمة، وقراصنة السماء يبحثون عنها أيضًا.

**مسار القصة:** مقدمة ← 4 رحلات، وكل رحلة تنتهي بجزيرة فيها قطعة من الخريطة ← **المعركة الأخيرة ضد سفينة القراصنة** ← النهاية وشاشة الشكر.

## ⬇️ تحميل اللعبة جاهزة (بدون Godot)
مع كل تحديث على GitHub تُبنى اللعبة تلقائيًا لثلاث منصات:
1. افتح المستودع على GitHub ثم تبويب **Actions**.
2. اختر آخر تشغيل ناجح ✅ باسم **Build game**.
3. في أسفل الصفحة، من قسم **Artifacts**، نزّل ما تريد:
   - **CloudShip-Windows**: فك الضغط وشغّل `CloudShip.exe`.
   - **CloudShip-Linux**: ملف واحد جاهز للتشغيل.
   - **CloudShip-Web**: نسخة للمتصفح، ويمكن رفعها على [itch.io](https://itch.io) ليلعبها أصدقاؤك من الرابط مباشرة.

### 🤖 تلعب وحدك؟ معك مساعدون آليون!
إذا انضم لاعب واحد فقط، ينضم معه تلقائيًا **مساعدون آليون**. عددهم 2 افتراضيًا، وتقدر تغيّره من 0 إلى 3 في الإعدادات. تعرفهم من **الهوائي الأخضر** على رؤوسهم، ويلعبون بالقواعد نفسها التي يلعب بها الإنسان تمامًا:
- **على السفينة:** الأول **بحّار سطح**: يصلح الثقوب، ويجلب الفحم، ويمسك الدفة عند اقتراب صخرة. والباقون **رماة** يبقون عند المدافع ويُسقطون الطيور والقنابل، وينزلون لإصلاح الثقوب عندما تهدأ السماء.
- **في الجزر يتبعونك ويساعدونك في كل لغز:**
  - يقفون عند الجدار العالي لتصعد على رؤوسهم، وإذا انتظرتَ هناك طويلًا يصعدون هم على رأسك ويسحبون الرافعة.
  - يثبتون ألواح البوابة ويركبون المصعد معك.
  - يديرون عجلة الريح لتطير، ثم يطيرون بعدك.
  - يقرعون جرسهم في اللحظة التي تقرع فيها جرسك.
  - يعبرون فوق الغيوم، ويلتقطون البلورات القريبة.
- إذا انضم صديق حقيقي، يأخذ مكان المساعد تلقائيًا.

### 🌐 اللعب مع أصدقاء بعيدين
اللعبة تعاونية على شاشة واحدة، لكن تقدرون تلعبونها معًا عبر الإنترنت بطريقتين:
- **Parsec** (مجاني): أنت تشغّل اللعبة، وأصدقاؤك يتصلون بجهازك ويلعبون بأيديهم وكأنهم عندك.
- **Steam Remote Play Together**: يعمل بالطريقة نفسها إذا أضفت اللعبة إلى Steam كـ "Non-Steam Game".

## 🎮 طريقة اللعب

### ⛵ المرحلة الأولى: الرحلة على السفينة
كل واحد في الطاقم يختار مهمته، وتتغير الأدوار باستمرار:

| المهمة | ماذا تفعل |
|---|---|
| 🔥 **المحرك** | خذ فحمًا من الصندوق وضعه في المحرك. إذا نفد الوقود تصبح السفينة بطيئة جدًا |
| ⚓ **الدفة** | ارفع السفينة أو اخفضها لتتفادى الصخور العائمة. الأسهم الحمراء على يمين الشاشة تحذّرك |
| 💣 **المدافع** | مدفع في المقدمة ومدفع فوق الصاري. أسقط طيور العاصفة واكسر الصخور (3 ضربات) |
| 🔨 **الإصلاح** | الطيور والصخور تُحدث ثقوبًا في السطح. قف بجانب الثقب واضغط التفاعل باستمرار. كلما زاد عدد المصلحين كان الإصلاح أسرع |

### 🏝️ المرحلة الثانية: الجزيرة العائمة
الجزر تتبادل: الرحلات الفردية تنتهي في **جزيرة الأزهار**، والزوجية في **جزيرة الرياح**.

**🌸 جزيرة الأزهار**
- **الجدار العالي**: لا يستطيع أحد القفز فوقه وحده. اقفز فوق رأس صديقك، ثم اسحب الرافعة لتظهر درجة يصعد عليها الباقون.
- **البوابة والألواح**: البوابة تبقى مفتوحة ما دام أحد واقفًا على لوح الضغط. من سيبقى في الخلف ليفتحها للآخرين؟
- **مصعد البالونات**: لا يرتفع إلا بعدد كافٍ من الركاب، وفي الأعلى رافعة تجعله يعمل وحده.

**🌬️ جزيرة الرياح**
- **فوّهة الريح**: تنفخ الريح إلى الأعلى ما دام أحدكم يُدير العجلة، والباقون يطيرون معها. وفي الأعلى عجلة ثانية ليرفع أحدكم آخرَ من بقي في الأسفل.
- **الأجراس المتزامنة**: أجراس متباعدة يجب أن تُقرع كلها في الثانية نفسها تقريبًا ليظهر الجسر. عدّوا معًا: 3، 2، 1!
- **الغيوم المتحركة**: غيوم لطيفة لها وجوه تنقلكم فوق الفراغ.

**في الجزيرتين:**
- **صندوق الكنز**: لا يُفتح إلا إذا اجتمع الطاقم كله حوله.
- **البلورات** 💎: مكافآت إضافية، وبعضها عالٍ جدًا ولا يُصل إليه إلا ببرج من الأصدقاء!

الصعوبة تزداد مع عدد اللاعبين ومع كل رحلة جديدة.

## 🕹️ التحكم

| | الحركة | القفز | التفاعل |
|---|---|---|---|
| **كيبورد 1** | `W A S D` | `Space` | `E` |
| **كيبورد 2** | الأسهم | `.` أو `Enter` | `/` |
| **يد التحكم** | العصا اليسرى أو الأسهم | `A` | `X` أو `B` |

- في القائمة: **اضغط زر القفز للانضمام**، ثم اختر بالأسهم واضغط **زر التفاعل**.
- لاعبان على الكيبورد، ويمكن أن يكون الجميع (حتى 6) بأيدي التحكم.
- **النزول من المنصات**: الأسفل + القفز.
- **المدفع**: الأعلى/الأسفل للتصويب (مدفع الصاري يدور بالأيمن/الأيسر أيضًا)، والقفز لإطلاق النار.
- **Esc** أو زر **Start**: استراحة، وفيها متابعة، وإعادة المرحلة، والإعدادات، والقائمة الرئيسية.
- **F11**: ملء الشاشة، و **M**: كتم الصوت.

### ⚙️ الإعدادات والحفظ
- **الإعدادات** (من القائمة أو من الاستراحة): صوت الموسيقى، وصوت المؤثرات، وملء الشاشة، والصعوبة (سهل / عادي / صعب)، وعدد المساعدين الآليين.
- **الحفظ تلقائي** بعد كل جزيرة، وخيار **«متابعة الرحلة»** في القائمة يكمل من حيث توقفتم.
- تُحفظ الإعدادات والتقدّم على جهازك، وتبقى بعد إغلاق اللعبة.

## 🚀 تشغيل اللعبة

1. نزّل **Godot 4.7** (النسخة العادية وليس .NET) من [godotengine.org](https://godotengine.org/download).
2. افتح Godot واضغط **Import** واختر ملف `project.godot` من مجلد اللعبة.
3. اضغط **F5** أو زر ▶️ للتشغيل.

> لتجربة مرحلة واحدة مباشرة: افتح `scenes/voyage.tscn` أو `scenes/island.tscn` واضغط **F6**، وسيضيف المحرك لاعبَين على الكيبورد تلقائيًا.

## 🔗 ربط GitHub مع Godot على جهازك

الفكرة ببساطة: المستودع على GitHub هو **النسخة الأصلية**، ونسخة على جهازك تفتحها بـ Godot. تعدّل على جهازك ثم ترفع التعديلات (Push)، وتسحب التعديلات الجديدة (Pull) من GitHub.

### الطريقة الأسهل: GitHub Desktop (أنصح بها)
1. نزّل [GitHub Desktop](https://desktop.github.com/) وسجّل الدخول بحسابك.
2. من القائمة: **File ← Clone repository**، واختر `moamlmushtaq/2dgame`، ثم حدّد مجلدًا على جهازك.
3. من الأعلى اختر الفرع (Branch) الذي فيه اللعبة، مثل `claude/bold-cori-f0jmgp`، أو `main` بعد الدمج.
4. افتح Godot ← **Import** ← اختر `project.godot` من المجلد نفسه.
5. بعد أي تعديل في Godot، ارجع إلى GitHub Desktop:
   - اكتب وصفًا قصيرًا في خانة **Summary** ثم اضغط **Commit**.
   - اضغط **Push origin** لرفع التعديل إلى GitHub.
6. لجلب تعديلات جديدة من GitHub (مثل التي أضيفها لك): اضغط **Fetch origin** ثم **Pull**.

### الطريقة الثانية: من سطر الأوامر
```bash
# مرة واحدة فقط
git clone https://github.com/moamlmushtaq/2dgame.git
cd 2dgame
git checkout claude/bold-cori-f0jmgp

# بعد كل تعديل
git add .
git commit -m "وصف التعديل"
git push

# لجلب التعديلات الجديدة
git pull
```

### الطريقة الثالثة: من داخل Godot نفسه (إضافة Git)
1. في Godot افتح تبويب **AssetLib** وابحث عن **Godot Git Plugin**، ثم ثبّتها.
2. أعد تشغيل المحرر، ثم من القائمة: **Project ← Version Control ← Version Control Settings**.
3. فعّل Git، وأدخل اسم المستخدم وبريدك. لكلمة المرور استخدم **Personal Access Token** من GitHub:
   GitHub ← Settings ← Developer settings ← Personal access tokens، مع صلاحية `repo`.
4. ستظهر لوحة **Commit** في المحرر، ومنها تقدر تعمل Commit و Push و Pull.

> 💡 مجلد `.godot/` محلي ولا يُرفع إلى GitHub (موجود في `.gitignore`)، ويُنشئه Godot تلقائيًا عند فتح المشروع.

## 📁 هيكل المشروع

```
project.godot            إعدادات المشروع
scenes/                  المشاهد: القائمة، القصة، الرحلة، الجزيرة
scripts/core/            اللاعب، التحكم، المساعدون الآليون، الحفظ والإعدادات والاستراحة، الرسم، السماء، الصوت، القوائم
scripts/voyage/          السفينة والمحطات والمخاطر وسفينة القراصنة وواجهة الرحلة
scripts/island/          الجزيرة والألغاز وواجهة الجزيرة
scripts/menu/            شاشة البداية، وكيف تلعب، والإعدادات، والقصة والنهاية
assets/fonts/            خط Cairo العربي (رخصة OFL)
export_presets.cfg       إعدادات التصدير: Windows و Linux و Web
.github/workflows/       البناء التلقائي على GitHub
```

### 📦 التصدير من Godot بنفسك
1. في Godot: **Editor ← Manage Export Templates ← Download and Install**.
2. **Project ← Export**، ثم اختر Windows أو Linux أو Web واضغط **Export Project**.

كل الرسومات مرسومة بالكود، فلا توجد صور خارجية. هذا يسهّل التعديل: غيّر الألوان أو الأشكال في الكود وسترى النتيجة فورًا.

والأصوات والموسيقى كذلك تُولَّد بالكود في `scripts/core/sound.gd`، فلا توجد ملفات صوت. توجد مقطوعتان: موسيقى حماسية للرحلة وموسيقى هادئة للجزيرة، وتُؤلَّفان في الخلفية عند بدء اللعبة.
