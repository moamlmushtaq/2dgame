# 🗺️ سفينة الغيوم: ماذا أنجزنا، وما الخطة القادمة

## ✅ ما أنجزناه

### 1. الأساس: النموذج الأول
- اخترنا فكرة **«سفينة الغيوم»**: طاقم سفينة طائرة يبحث عن قطع خريطة السماء.
- محرك **Godot 4.7**. كل الرسومات مرسومة بالكود، بدون صور خارجية.
- الواجهة كلها بالعربية بخط **Cairo**.
- من **1 إلى 6 لاعبين** على شاشة واحدة: لاعبان على لوحة المفاتيح، والباقون بأيدي التحكم.
- **الرحلة على السفينة**، وفيها أربع مهام: المحرك والفحم، والدفة لتفادي الصخور، ومدفعان ضد طيور العاصفة، وإصلاح الثقوب.
- **جزيرة الأزهار** وألغازها: جدار عالٍ لا يُتجاوز إلا بالصعود على رأس صديق، وبوابة بألواح ضغط، ومصعد بالونات، وصندوق كنز لا يُفتح إلا باجتماع الطاقم كله.
- البحّارة يمرّون عبر بعضهم، لكن رأس كل واحد منصة يقف عليها الآخرون.

### 2. الصوت وجزيرة ثانية
- كل **الأصوات والموسيقى تُولَّد بالكود**، فلا توجد ملفات صوت. توجد مقطوعتان: واحدة للرحلة وواحدة للجزيرة.
- **جزيرة الرياح**: فوّهة ريح تعمل بعجلة يديرها أحدكم، وأجراس يجب أن تُقرع في اللحظة نفسها، وغيوم متحركة لها وجوه.

### 3. لعبة متكاملة
- **قصة** لها بداية ونهاية: مقدمة، ثم 4 قطع خريطة، ثم **معركة أخيرة ضد سفينة القراصنة**، ثم النهاية وشاشة الشكر.
- قائمة رئيسية فيها: متابعة، ورحلة جديدة، وكيف تلعب، والإعدادات، والخروج.
- **استراحة** بزر Esc أو Start.
- **الإعدادات**: صوت الموسيقى والمؤثرات، وملء الشاشة، والصعوبة، وعدد المساعدين. تُحفظ على الجهاز، ومعها **حفظ تلقائي** للتقدّم.
- **بناء تلقائي على GitHub** لنسخ جاهزة للعب على Windows و Linux والمتصفح.

### 4. المساعدون الآليون
- من يلعب وحده يحصل على مساعدين آليين، ويلعبون بالقواعد نفسها التي يلعب بها الإنسان.
- **على السفينة:** مساعد للإصلاح والفحم والدفة، ورماة عند المدافع.
- **في الجزر:** يساعدون في كل لغز: يصعدون على رأسك أو تصعد على رأسهم، ويثبتون ألواح البوابة، ويديرون عجلة الريح، ويقرعون الأجراس معك، ويعبرون الغيوم.
- **اختبارات آلية** في مجلد `tests/` تتأكد أن كل هذا يعمل. طريقة تشغيلها في `CLAUDE.md`.

## 🧭 الخطة القادمة (مرتبة حسب الأولوية)

### المرحلة 1: التجربة والتلميع (ابدأ بها)
- [ ] **جرّب اللعبة بنفسك ومع أصدقاء**، ودوّن ما كان صعبًا أو مملًا أو غير واضح. هذا أهم شيء الآن.
- [ ] **جرّب أيدي التحكم الحقيقية.** لم تُجرَّب على جهاز حقيقي، فقط بالكيبورد المُحاكى.
- [ ] **اسمع الأصوات والموسيقى.** لم نسمعها أبدًا، لأن بيئة التطوير ليس فيها صوت. عدّل أي صوت مزعج.
- [ ] **ضبط الصعوبة** بعد اللعب الحقيقي. حاليًا: المساعدون وحدهم (والإنسان واقف لا يلعب) يفوزون بالرحلة العادية تقريبًا 3 من كل 4 مرات، وبمعركة القراصنة تقريبًا 2 من كل 3.
- [ ] **نسخة المتصفح:** تأكد ألا تتوقف لحظات عند البداية بسبب تأليف الموسيقى.

### المرحلة 2: محتوى جديد
- [ ] **جزيرة ثالثة: جزيرة الجليد.** أرضية زلقة، وجليد يذوب بنار المحرك، وكتل ثلج تُدفع معًا.
- [ ] **ألغاز جديدة في الرحلة:** عاصفة برق تُطفئ المحرك، ورياح جانبية تميل بالسفينة، ومطر يُطفئ النار.
- [ ] **أنواع أعداء جديدة:** طائر كبير يحتاج عدة ضربات، وسحابة سوداء تمطر قنابل.
- [ ] **مراحل مختلفة للقراصنة:** مرحلة ثانية تقترب فيها سفينتهم ويقفز منها قراصنة على سطح سفينتكم.

### المرحلة 3: شخصيات وتخصيص
- [ ] **قبعات وأزياء للبحّارة** تُشترى بالبلورات المجمّعة.
- [ ] **تغيير لون السفينة وشكل البالون.**
- [ ] **إنجازات:** مثل «أنهيتم رحلة بدون ثقوب»، و«جمعتم كل البلورات».

### المرحلة 4: اللعب عبر الإنترنت (مشروع كبير)
- [ ] حاليًا تقدرون تلعبون عن بُعد عبر **Parsec** أو **Steam Remote Play**.
- [ ] الخطوة الكبيرة: لعب أونلاين داخل اللعبة بنظام الشبكات في Godot. يحتاج إعادة تصميم كيف تُقرأ الأزرار، بحيث تأتي من الشبكة بدل الجهاز، ومزامنة الأعداء والثقوب.

### المرحلة 5: النشر
- [ ] رفع نسخة المتصفح على **itch.io** ليلعبها الأصدقاء من رابط.
- [ ] أيقونة وصور ترويجية وفيديو قصير.
- [ ] دمج الفرع `claude/bold-cori-f0jmgp` في `main` عن طريق Pull Request على GitHub.

## 💻 كيف تكمل بـ Claude Code على جهازك

1. **جهّز الأدوات:** Git، و **Godot 4.7**، و **Claude Code**.
2. **انسخ المستودع** وادخل الفرع:
   ```bash
   git clone https://github.com/moamlmushtaq/2dgame.git
   cd 2dgame
   git checkout claude/bold-cori-f0jmgp
   ```
3. **شغّل Claude Code داخل المجلد** بالأمر `claude`. سيقرأ ملف `CLAUDE.md` تلقائيًا ويعرف كل شيء عن المشروع.
4. **أخبره أين Godot على جهازك** حتى يستطيع تشغيل الاختبارات. مثلًا:
   > «برنامج Godot موجود في `C:\Godot\Godot_v4.7.2-stable_win64.exe`، استعمله للاختبارات»

   ملاحظة: الاختبارات مكتوبة بـ bash، فعلى Windows شغّلها من **Git Bash**.

### أمثلة لطلبات تكتبها له
